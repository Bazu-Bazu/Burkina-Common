# Common

> Общая библиотека с переиспользуемыми компонентами для сервисов экосистемы Burkina.

**Common** — это набор общих компонентов и инфраструктурных решений, используемых различными сервисами экосистемы Burkina.

Основная задача модуля — централизовать общую функциональность и избежать её дублирования в отдельных проектах.
